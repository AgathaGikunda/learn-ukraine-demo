How field data is collected and feeds this dashboard
The gap this system fills The Independent Verification Agency (IVA) confirms DLR achievement periodically for disbursement — but does not tell MoES which schools still have no shelter, which oblasts are behind on G8 teacher training, or which schools have not confirmed textbook receipt. This KoboToolbox + Power BI pipeline provides real-time operational visibility between IVA verification cycles, at school and oblast level.
